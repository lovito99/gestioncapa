# Cobro de cursos

Esta carpeta divide la documentación operativa de HU-53 y HU-32 por responsabilidad.
El archivo histórico [cobroCursos.md](../cobroCursos.md) se conserva como snapshot
compatible: sus enlaces, referencias de versiones anteriores y evidencia registrada no
se modifican.

- [Política de cobro](politica.md): oferta, inscripción, acceso y constancias.
- [Pasarelas y medios](pasarelas.md): Izipay, Culqi, transferencia y efectivo.
- [Operación y recuperación](operacion.md): migración, vencimientos y reversión segura.
- [Evidencia de calidad](evidencia.md): límites de aceptación y controles de entrega.

Los cambios futuros deben hacerse en el archivo de la responsabilidad correspondiente;
solo se actualiza el snapshot histórico si una tarea pide explícitamente modificarlo.
